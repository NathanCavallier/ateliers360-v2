## 1) Découverte Robotique — “Mon premier robot”

Accroche : Construis et programme ton robot en 1 demi-journée.
Description : Initiation pratique à la robotique avec kits mBot / Arduino préconfigurés. Les participants montent un robot, programment des comportements simples et réalisent des mini-défis (ligne, évitement d’obstacle).
Objectifs : Comprendre capteurs / actionneurs, logique séquentielle, introduction au code.
Public : 8–12 ans.
Durée : 3 heures (demi-journée).
Matériel fourni : kit robot, PC/tablette, feuilles d’activités.
Tarif conseillé : 120€ / demi-journée (groupe de 10 enfants) — +10€ / enfant supplémentaire.

---

## 2) Robotique Avancée — “Compétition mini-robots”

Accroche : Construis une stratégie et fais gagner ton équipe.
Description : Ateliers par équipes pour concevoir, coder et optimiser un robot pour un défi (parcours, sumo, ramassage). Mécanique, capteurs, calibration et itérations.
Objectifs : Travail en équipe, prototypage rapide, mise au point algorithmique.
Public : 12–17 ans.
Durée : 1 journée.
Matériel : kits robots, capteurs, outils, table challenge.
Tarif : 400€ / journée (jusqu’à 12 participants).

---

## 3) Code Fun — “Créer ton premier jeu”

Accroche : De l’idée au jeu jouable en 2 sessions.
Description : Utilisation de Scratch ou p5.js/HTML pour créer un mini-jeu. Design, logique, collision, scoring et partage.
Objectifs : Logique de programmation, créativité, débogage.
Public : 10–15 ans.
Durée : 2 x 1.5h ou 1 demi-journée.
Matériel : PC/tablettes.
Tarif : 150€ / demi-journée (groupes de 10).

---

## 4) IA pour les jeunes — “Comprendre et créer un mini-chatbot”

Accroche : Découvre l’IA et crée ton assistant de classe.
Description : Atelier d’initiation à l’IA (concepts simples), création d’un mini-chatbot guidé (règles + prompts), sensibilisation éthique. Usage d’outils low-code/plateforme pédagogique.
Objectifs : Démystifier IA, construire un chatbot, comprendre enjeux éthiques.
Public : 13–18 ans.
Durée : 3 heures.
Matériel : PC/tablettes, accès internet.
Tarif : 180€ / atelier (groupes de 10).

---

## 5) Mini-labo Physique-Chimie — “Expériences qui impressionnent”

Accroche : La science en live — safe et spectaculaire.
Description : Animations d’expériences sûres (chimie colorée, électricité simple, pression/air) avec explication scientifique.
Objectifs : Curiosité scientifique, méthode expérimentale, sécurité.
Public : 8–14 ans.
Durée : 1h ou 2h.
Matériel : kits labo, lunettes, gants.
Tarif : 100€ / séance 1h.

---

## 6) Web & Design — “Ma page web en 2h”

Accroche : Crée ton mini-site et partage-le.
Description : Apprendre HTML/CSS de base ou utiliser un builder simple pour créer un portfolio/mini-site. Introduction à l’UX simple.
Objectifs : notion web de base, publication, design simple.
Public : 13–18 ans / lycéens.
Durée : 2h.
Matériel : PC, hébergement (optionnel).
Tarif : 130€ / atelier (10 participants).

---

## 7) Sécurité numérique pour famille — “Internet sûr à la maison”

Accroche : Protéger sa famille en 90 minutes.
Description : Atelier parents-enfants sur mots de passe, vie privée, réseaux sociaux, cyberharcèlement. Exercices pratiques.
Objectifs : bonnes pratiques, sensibilisation.
Public : familles.
Durée : 1.5h.
Matériel : supports imprimés, slides.
Tarif : 180€ / session familiale (jusqu’à 6 personnes).

---

## 8) Stage Vacances — “Code & Robotique” (3 jours)

Accroche : Stage intensif pour créer, coder et présenter un projet.
Description : 3 jours de projet avec objectifs (robot + mini-jeu + présentation finale). Encadrement, matériel, diplôme.
Objectifs : gestion de projet, prototypage, soft skills.
Public : 10–16 ans.
Durée : 3 jours (6–7h/jour).
Matériel : kits, PC, fournitures.
Tarif : 150–250€ / participant (selon matériel inclus).

## 9) Atelier Orientation — “Métiers du numérique”

Accroche : Découvre les parcours, les jobs et comment y arriver.
Description : Conférence atelier + Q&A avec exercices pour construire son parcours. Idéal pour lycées.
Objectifs : information réaliste, plan d’action, mini CV.
Public : lycéens, étudiants.
Durée : 1h30.
Tarif : 120€ / séance.
