### Section "Notre méthode de développement"

```
Titre H2 : Comment nous travaillons

Philosophie :
Nous pratiquons un développement itératif — vous voyez le produit
prendre forme dès les premières semaines, pas uniquement à la livraison finale.
Chaque étape est validée ensemble avant de passer à la suivante.

Phase 1 — Cadrage (1 à 2 semaines) :
Définition précise du périmètre, des utilisateurs cibles, des fonctionnalités
prioritaires et du planning. Livrable : cahier des charges validé + maquettes
fonctionnelles (wireframes).

Phase 2 — Prototype (2 à 4 semaines) :
Développement d'une version cliquable de l'application avec les fonctionnalités
principales. Permet de tester et de valider l'expérience utilisateur
avant le développement complet.

Phase 3 — Développement (4 à 16 semaines selon périmètre) :
Développement itératif par sprints de 2 semaines. À chaque sprint,
une démo des fonctionnalités développées. Vous pouvez ajuster les priorités
en cours de route.

Phase 4 — Tests & recette (1 à 3 semaines) :
Tests fonctionnels, tests de performance, tests de sécurité.
Corrections des anomalies identifiées. Formation de vos équipes.

Phase 5 — Mise en production & suivi (J0 + 1 mois) :
Déploiement en production, surveillance des performances,
correction des premiers retours utilisateurs. Support inclus 1 mois.
```
