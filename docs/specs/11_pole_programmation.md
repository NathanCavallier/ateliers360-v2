# Spécifications : Pôle 2 – Programmation & Création Numérique 💻

**Objectif Pédagogique** : Coder pour créer. Sortir de la consommation pour aller vers la production.
**Cible** : Du primaire (Scratch) aux étudiants (Web/Python).

## 1. Fonctionnalités Clés

### A. Parcours de Création

* [ ] **Progression par Niveaux**
  * Niveau 1 : Blocs (Scratch / MakeCode).
  * Niveau 2 : Scripting (Python).
  * Niveau 3 : Web/App (HTML/JS/Frameworks).
* [ ] **Personnalisation**
  * Adaptation des parcours selon l'âge et la rapidité de l'apprenant.

### B. Projets Créatifs & "Side-Projects"

* [ ] **Typologies de Projets Supportés**
  * Jeu Vidéo (Lien vers projet Scratch ou exécutable).
  * Site Web (Hébergement simple ou lien).
  * Mini-App / Script utilitaire.
* [ ] **Showcase**
  * Mise en valeur visuelle du résultat (Screenshot / GIF animé).

### C. Dépôt & Rendu

* [ ] **Système de Soumission**
  * Champs : Lien Replit/GitHub, Zip du code, Vidéo de démo (Screencast).
  * Commentaires de l'apprenant : "J'ai voulu faire ça, mais j'ai bloqué sur..." (Pédagogie de l'erreur).
* [ ] **Revue de Code**
  * Interface pour l'animateur pour annoter des bouts de code (façon Git simple).

### D. Portfolio Numérique (Clé pour Collège/Lycée)

* [ ] **CV Maker**
  * Génération automatique d'une page "Portfolio" agrégeant les meilleurs projets.
  * Export PDF pour dossiers scolaires (Parcoursup / Stages).
* [ ] **Badges de Compétences**
  * "Développeur Web Junior", "Pythonista", "Game Designer".

### E. Évaluation Qualitative

* [ ] **Critères Soft-Skills Tech**
  * Logique algorithmique.
  * Autonomie dans le debug (Google-fu).
  * Créativité / Design.
  * Clarté du code (Clean Code).

## 2. Priorités

1. Dépôt de productions (Lien + Description).
2. Portfolio généré (Valeur ajoutée forte pour les parents/jeunes).
