# Spécifications : Fonctionnalités Avancées & Spécifiques 🚀

**Priorité** : P3 (Futur / Innovation)
**Statut** : R&D

Ce qui fera la différence entre Ateliers 360 et une gestion classique.

## 1. IA & Automatisation (ImuChat / ImuLabs Core)

* [ ] **Assistant Pédagogique (Alice)**
  * Chatbot contextuel capable de répondre aux questions techniques des élèves sur les supports de cours.
  * Aide à la préparation pour l'animateur ("Génère moi un quiz sur Arduino").
* [ ] **Intelligence des Données**
  * Résumé automatique des séances (basé sur les notes + audio si dispo).
  * Détection des élèves en décrochage (basé sur présence + participation + résultats quiz).
  * Suggestions d'activités personnalisées pour un groupe (selon ce qu'ils ont aimé).

## 2. Modularité & Évolutivité

* [ ] **Système de Modules**
  * Architecture plugin pour activer/désactiver des pans de l'app (ex: Module "Cantine", Module "Transport", Module "Code Review").
* [ ] **Templates de Parcours**
  * Création de modèles de cours réutilisables d'année en année.

## 3. Spécificités Ateliers 360 (Différenciation)

* [ ] **Carnet de Parcours Exportable**
  * Génération d'un PDF "Diplôme" / "Relevé de compétences" beau et pro en fin d'année.
  * QR Code vérifiable vers le portfolio en ligne de l'élève.
* [ ] **Mode "Atelier Itinérant"**
  * Gestion de "Kits Matériel" (Inventory Management) : Savoir où est la valise Arduino #3.
  * Checklists départ/retour matériel pour l'animateur.
* [ ] **Vitrine Publique (Showcase)**
  * Page publique automatique avec les meilleurs projets (avec consentement) pour montrer aux parents/partenaires.

## 4. Priorités d'Implémentation

1. Carnet de Parcours (Valeur ajoutée forte pour les parents).
2. Gestion Inventaire (Si beaucoup de matériel itinérant).
3. IA Assistant (Proto).
